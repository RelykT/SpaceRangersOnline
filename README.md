# Кромка

Браузерная космическая песочница реального времени. Галактика, цены, пилоты и войны собираются из зерна и живут, пока открыта вкладка. Своя вселенная: народы Солари, Регнары, Нимвы, Векты и рой Абсолют. Чужих имён, кораблей и текстов здесь нет.

Игра рассчитана и на мышь, и на телефон в альбомной ориентации.

## Как запустить

Нужен Node.js 20 или новее.

```bash
npm install
npm test
npm run dev
```

Откройте `http://localhost:5173/SpaceRangersOnline/` — такой базовый путь нужен и локально, и на GitHub Pages.

Сборка: `npm run build`, просмотр сборки: `npm run preview` (тот же префикс, порт 4173).

## Как играть

«Новая игра» ведёт по шагам: народ, стартовая карьера, имя и портрет, размер края, сложность, нрав Абсолюта, живость биржи и зерно. Карьера задаёт первый корпус, фит, деньги и начальные навыки. Дальше она ничего не запирает.

Кнопка «Пилот» показывает опыт, семь навыков (точность, манёвренность, техника, торговля, обаяние, лидерство, разведка), освоение корпусов и групп орудий и звания рас. Очки тратятся в любой момент, мир при этом не встаёт на паузу. «Клинок» просит освоение лёгких корпусов, крейсер — ударных, линкор — крейсеров и звание у хозяина верфи. Второе и третье поколение орудий просят освоение своей группы.

Вы появляетесь в домашнем доке своего народа. Мир не ждёт: рынок, чужие корабли и войны тикают и в доке. Пауза есть только в меню (Esc) и когда вкладка скрыта. В бою отдельной паузы нет.

Петля: рынок → верфь → контракт → система → стыковка. Цена падает, если залить товар, и растёт, когда запас кончается. Войны, эпидемии и налёты двигают спрос. Торговцы других народов сами возят грузы.

Щит лучше держит кинетику и взрыв, броня — ЭМ и термал. Орудие имеет оптимум и спад. Фиксатор «Клинч» запрещает прыжок и глушит маршевый «Штурм». Захват цели нужен, чтобы ваши орудия стреляли.

Потеря корпуса оставляет обломки, возвращает часть стоимости страховкой и сажает вас на новую «Искру» в последнем доке.

Сохранение пишется само на это устройство (IndexedDB и localStorage). «Экспорт» скачивает файл, «Импорт» на главном экране поднимает его на другом компьютере или телефоне.

## Управление

Одинаковые приказы на компьютере и на телефоне. Панели не пропускают нажатие в космос. Если под курсором или пальцем несколько объектов, открывается список — игра не угадывает. Зона касания не меньше 44 пикселей и не зависит от того, насколько мелко нарисован корабль. Любую цель можно выбрать из списка «Обзор» справа, без точного тыка.

### Мышь и клавиатура

- Пустой космос — лететь в точку.
- Объект — выбрать и открыть кольцо: приблизиться, орбита, держать дистанцию, захват, стыковка, прыжок.
- Колесо — масштаб, перетаскивание — сдвинуть камеру. «Следить» возвращает камеру к кораблю.
- `F1`–`F8` — верхние слоты, `1`–`8` — средние и нижние.
- `Tab` — следующая цель, пробел — стоп, `M` — карта галактики, `Esc` — меню.

### Палец

- Касание пустоты — лететь, касание объекта — выбрать.
- Удержание — кольцо приказов.
- Щипок — масштаб, два пальца — сдвиг камеры. Один палец карту не тащит.
- Крупные кнопки модулей снизу.
- Телефон лучше держать горизонтально: обзор остаётся сбоку, модули — снизу.

На карте то же самое: касание выбирает систему, список систем справа выбирает её без прицеливания, «Проложить маршрут» начинает прыжки. Прыжок идёт в реальном времени, фиксатор его срывает.

## Архитектура

`src/sim` — авторитетное ядро. Оно не знает про DOM, canvas и частоту кадров. Состояние — обычные данные. Шаг `step(world, commands)` длится фиксированные 1/20 секунды. Случайность только из зерна, через хеши, поэтому одинаковые команды дают одинаковый мир. Так ядро потом можно поднять на сервере: клиент шлёт команды, сервер считает тики.

`src/render` и `src/game` — картинка, ввод и сохранения. Попадание по объектам считается в `src/input` отдельно от спрайта. Жесты (касание, перетаскивание, долгое нажатие, щипок) тоже отделены, чтобы пороги можно было проверить тестами.

В ядре уже есть роли пилотов (торговец, охотник, пират, патруль, разведчик, рой), характер, память об обиде, риск и бегство, вызов помощи, фит в пределах сети и процессора, война за системы.

Тесты: `npm test` (детерминизм генерации, экономика, ограничения фита, урон по сопротивлениям, фиксатор, попадание и жесты).

## GitHub Pages

Сайт рассчитан на `https://relykt.github.io/SpaceRangersOnline/`.

В репозитории есть workflow `.github/workflows/pages.yml`: на каждый push в `main` он гоняет тесты, собирает проект и публикует папку `dist`. Владельцу нужно один раз включить Pages: Settings → Pages → Build and deployment → Source: **GitHub Actions**. Пока источник не переключён, workflow отработает, но сайт не откроется.

## Что упрощено

- Один корабль у капитана, склад модулей летает с ним.
- Попадание упрощено относительно «настоящей» баллистики: дистанция, угловая скорость и сигнатура, без отдельных снарядов.
- Чужие бои идут по тем же правилам, но без анимации очередей вне вашей системы — позиции и урон всё равно считаются.
- Верфь продаёт модули без лимита склада, но только своего техуровня.
- Мультиплеер не включён: нет сети, есть только форма шага «команды → новое состояние».
